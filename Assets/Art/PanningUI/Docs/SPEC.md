2. **넘김(Q2 가)**: 탭하면 즉시 보상 팝업으로. 안 누르면 **1.2초 뒤 자동**(자동 도전 흐름이 끊기지 않게). 연출 등장 0.35초는 1.2초에 포함.

## 4-3. 글자와 PNG — 로컬라이징 규칙 (사용자 2026-09-26)
- **PNG에 글자를 굽지 않는다.** 모든 문구는 로컬라이즈 텍스트(TextMeshPro)로 PNG 바탕 위에 올린다. 멋 낸 글자(기울임·그라데이션·외곽선·그림자)도 폰트 머티리얼로 만든다.
- **예외 = 등급 글자 E·D·C·B·A·S·SS·SSS·SR·SSR·UR·LR·MR**(언어와 무관한 기호, `GradeLetter/` 13장). 숫자·기호(?, ▲)도 폰트로.
- **r4에서 해결**: 글자 든 PNG 4개 삭제 → `ui_rev_tag_equipped_bg`·`ui_rev_tag_new_bg`·`ui_idle_badge_max_bg`(글자 없는 바탕) + TMP 텍스트. "클리어!" PNG 없음(TMP만). 제목 띠의 "//" 표식은 글자가 아니라 도형(기울인 막대 2개)이라 띠 PNG에 포함.
- **이모지 금지(사용자 2026-09-27 "절대 이모지를 쓰지 마. 아이콘은 전부 그릴 거니까")**: 게임 UI 어디에도 이모지(시스템 이모지 폰트)를 쓰지 않는다. v48의 이모지 자리는 전부 **직접 그린 아이콘 스프라이트**로 바꾼다 — 목록 `icon-list.csv`. r4 시안의 점선 네모 = 그릴 아이콘 자리.
- 아스트라 요청(아이콘)도 글자 없는 그림만 받는다.
