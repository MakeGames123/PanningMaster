# 사용자 후속 지시 — 2026-09-28

패키지 사양보다 이후 대화의 아래 확정 사항을 우선한다. `SPEC.md`, `UNITY_AGENT_GUIDE.md`, `unity-import.csv`는 T01-a 패키지 원본을 그대로 동기화하므로 이 문서와 함께 읽는다.

- 리볼버의 빛바램, 반사광, 애니메이션, 빛 번짐 강조 프레임을 사용하지 않는다. 카드 프레임은 일반형이다.
- 총 전투력 동률은 중립색 `0`이며 상승 화살표를 표시하지 않는다. 감소하는 개별 수치는 빨강이다. 실시간 계산 연결은 후속 단계다.
- 아이콘과 무기 그림은 투명한 빈 Image 슬롯이다. 이모지를 넣지 않는다. 모든 문구는 폰트를 직접 지정한 TMP다.
- 기본 BMJUA, `Assets/TextMesh Pro`, 기존 게임의 Resources/Script/씬과 PlayFab SDK를 수정하지 않는다.
- 프리팹은 `Popup` + 용도, 홈은 `ScreenMainHome`으로 명명한다.
- 던전 클리어/결과 화면은 시안 수정 대기다. 현재 시안으로 후속 제작하지 않는다.
- 남은 팝업과 홈을 파일로 먼저 준비하고 사용자 판별은 한 번에 한다. 게임 동작 연결도 이후 일괄 진행한다.
- 이번 닫기 X 교체에 한해 Unity 재저장과 3종 Game View 캡처를 지금 실행하도록 사용자가 승인했다. 이후 전체 화면 원격 검수는 별도 시점에 진행한다.
- 새 X는 제공 PNG 그대로, Simple / 132×138 / 왼쪽 위 기준 (534,2424), 중앙 x=600이다. 모양과 색을 변경하지 않는다.
- 홈은 기존 `home-skin-r01` 제안 소스를 기반으로 준비한 검수안이다. r4 확정 홈으로 표시하지 않는다. 원본 출처/해시는 `home-ui-layout.json`에 기록했다.
- 커밋 및 푸시를 하지 않는다.

현재 결과와 다음 검수 대상은 `Validation/ui-batch-delivery.md`를 참조한다.

## 2026-09-28 사용자 추가 정정 — 홈 원본과 내비

- 던전 수정은 사용자가 나중에 다시 요청한다. 자동 제작하지 않는다.
- 기본 내비는 7칸 중 가운데 X 자리를 비운다. X는 팝업 문맥에만 존재한다. 홈 6메뉴는 0/1/2/4/5/6번 칸이다.
- 사용자는 홈에 별도로 만들어둔 에셋을 지목했다. 기존 home-skin-r01 검수안이 원하는 에셋 기반 홈이라는 보장은 없으므로 완성 홈으로 배포하지 않는다. HUD/Inventory 제공 PNG가 Unity에 있지만 홈 참조는 없음을 확인했다. 현재 해당 에셋이 사용자 지목본인지 질문한 상태이며 원본 확정 전 임의 대체하지 않는다.


## 2026-09-28 최종 사용자 정정과 푸시 승인
- 카카오톡 받은 파일 원본을 사용자가 재지목했다. **채팅 요약(파일명 notice의 실제 의미), 퀘스트, 재화 프레임, 최적 편성** 네 종류만 홈에 적용한다.
- 슬롯5색 및 장착중 PNG는 사용하지 않는다. 다른 홈 구성도 아직 시안이 끝나지 않아 이후 교체할 임시 표시다. 이 부분을 완성 홈으로 표기하지 않는다.
- 네 가지만 기존 원본과 동일 해시의 Sprite로 적용했다. 채팅 배경+말풍선은 같은 사각형에 정렬, 원본 종횡비 유지. 기존 텍스트는 TMP이며 말풍선·퀘스트 화살표와 겹치지 않게 여백을 조정했다.
- 홈 자체 Preview도 Expand/SafeArea/Column 대응 완료. 7칸 기본 내비의 가운데는 빈칸이고 팝업 소유 X만 문맥에 따라 표시한다.
- 사용자가 작업 종료 후 `https://github.com/MakeGames123/PanningMaster.git`에 푸시하고 개발자 전달/작업 방법까지 정리하도록 명시적으로 승인했다. 이 요청에 한해 이전 commit/push 금지를 해제한다. 기존 개발자 변경분은 제외한다.
